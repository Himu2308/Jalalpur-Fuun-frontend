# Jalalpur Fun User Log Android app

This Android WebView app opens the production user log page at
`https://jalalpur-fuun-frontend.onrender.com/userlog`.

Build locally with Java 17, Android SDK 35, and Gradle 8.13:

```sh
gradle assembleDebug
```

The installable APK is generated at `app/build/outputs/apk/debug/app-debug.apk`.
